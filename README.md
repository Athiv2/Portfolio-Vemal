## Run Locally

1. Download or clone the repository:
   ```bash
   git clone https://github.com/athiv2/Portfolio-Vemal.git
   ```
2. Open `index.html` in any modern browser.

## Update the Site

1. Edit or upload the changed files on GitHub (**Add file → Upload files**).
2. Commit the changes.
3. Wait 1–2 minutes for GitHub Pages to redeploy, then hard refresh (Ctrl + Shift + R).
